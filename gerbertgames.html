Gerbert Games

A local multiplayer party game for two to four players, fighting over tile arenas that float above a black hole.

01 // Why

Why I made it

We wanted a party game that's as much fun in the room as on the screen: simple rules, lots of chaos, and moments that get friends shouting at each other.

Real-life challenges that pop up mid-match push that further, so the game spills out into the room.

02 // How

How I built it

As producer I set up the GitHub repo, ran planning and meetings, and kept minutes so everyone knew what was next.

As tech lead I built the 15×15 procedural tile arena every mode shares, plus the mode logic, respawning, dash and grab, the HUD, and the end screen, all as reusable Blueprints with clear naming so the team could build on them safely.

I also did the audio with MetaSounds and procedural sound, which was new to me, so repeated actions don't sound identical every time.

Built with

03 // Play

Play Colour Tiles

Colour Tiles is one of the four modes in Gerbert Games: run over tiles to claim them, and whoever owns the most when time runs out wins.

This is a cut-down version I rebuilt for the web. You get 20 seconds against a bot, and the dash from the real game for cutting into its territory.

This mini game needs JavaScript turned on.

05 // Looking back

What I'd do differently

Early workload planning is where I'd improve. Once I got consistent with meeting notes and task organisation, the team's progress picked up a lot.

It pushed me to learn new systems, take responsibility for large parts of the game, and balance leading the team with building it.

06 // Features

What's in it

  • Local multiplayer for 2–4 players with controller support
  • Customisable Gerberts with selectable heads, colours, and shape markers
  • A playable main menu with spaceship cursors, game mode voting, collisions, and explosions
  • Four tile-based game modes: Health Tiles, Time Tiles, Colour Tiles, and Gauntlet
  • A 15×15 procedural tile arena shared by every mode
  • Health tiles that lose durability, change colour, and fall
  • Time tiles that count down after you step on them
  • Colour tiles you claim by running over them
  • Gauntlet scoring that tracks placements across rounds
  • A dash for knocking opponents back
  • A grab for picking opponents up and moving them
  • Random real-life challenges during matches
  • Tutorial screens that explain each mode before it starts
  • Controller-friendly character customisation
  • Game mode voting before each match
  • Procedural sound for repeated interactions
