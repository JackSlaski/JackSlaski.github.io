    Arms & Assets

    A systems-driven multiplayer project focused on combat, inventory, player economy, trading, item progression, and modular gameplay systems.

    Active Development

    Project Information

    • Project Type: Personal Project
    • Development: Solo
    • Engine: Unreal Engine 5

    • Focus: System Design and Technical Implementation
    • Platform: PC

    Project Overview

    Arms & Assets is a systems-driven multiplayer project inspired by the freedom and player economies found within Garry's Mod roleplay servers.

    The project explores modular combat systems, unique items, inventory management, trading, player ownership, economy design, progression, and administrative tools within Unreal Engine 5.

    Development currently focuses on producing clean, reusable Blueprint systems that can be expanded safely as the project grows.

    Current Development

    The project is currently in active development. Systems, visuals, balancing, interfaces, and project scope may continue to change while features are implemented and tested.

    Current work includes weapon systems, randomly generated item statistics, inventories, item identification, upgrading, gem slots, player analytics, administrative interfaces, and persistent ownership data.

    Systems In Development

    Combat

    Modular weapons, random statistics, upgrading, attachments, gems, and item variation.

    Inventory

    Grid-based storage, item movement, tooltips, ownership data, and persistent item identities.

    Economy

    Player trading, item value, progression, ownership, and wider economic systems.

    Administration

    Administrative interfaces, analytics, player monitoring, and system controls.
