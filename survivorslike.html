Survivors Like

Information

  • Team Size: Solo Project
  • Role: Game Prototype Development
  • Time Frame: 8 Weeks
  • Engine: UE5
  • Grade Achieved: 71%

Description

This project is a fast-paced survivors-like arena shooter developed in Unreal Engine 5. Players must survive against increasingly difficult waves of enemies by combining movement, projectile combat, and powerful area-of-effect abilities. As the match progresses, enemies become more numerous and aggressive, requiring players to carefully manage their health, ability cooldowns, and positioning to stay alive.

A major focus of the project was the implementation of game feel principles, using responsive controls, layered feedback, visual effects, sound design, and satisfying combat interactions to create an engaging player experience. The project was developed as part of a university module focused on game feel and player feedback systems.

Features

  • 360° Mouse-Aimed Projectile Combat
  • Bouncing Projectiles With Physics-Based Reactions
  • Four Unique Area-of-Effect Abilities (Shockwave, Raise Hell, Enemy Freeze, Explosive Mine)
  • Wave-Based Enemy Survival Gameplay
  • Momentum-Based Character Leaning
  • Modular Segmented Health System
  • Ability Cooldowns With Animated UI Feedback
  • Damage Numbers and Combat Feedback Systems
  • Enemy Knockback and Death Effects
  • Layered Audio and Visual Effects
  • Game Feel Focused Design and Implementation
