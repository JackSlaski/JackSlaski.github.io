Cave Generation Tool

A procedural cave generator for Unreal Engine 5, written in C++ with a custom cellular automata system.

01 // Why

Why I made it

Building cave layouts by hand in Unreal is slow.

I wanted a tool that generates one in seconds, with enough settings that a designer stays in full control of the result.

02 // How

How I built it

It's written in C++ for speed. A cellular automata system, inspired by Conway's Game of Life, fills a 2D grid at random, then neighbour rules smooth it into caves over several passes.

Seeds make results repeatable, and corridors and rooms, with optional loot, are carved on top.

Every value is exposed in the Details panel, so designers can tune the output without touching code.
